Student Management API -----

A beginner-friendly REST API built using FastAPI to manage student records.

Features ->

Get all students
Get a student by ID
Add a new student
Update complete student details using PUT
Partially update student details using PATCH
Delete a student
Search students by course using query parameters
Validate input data using Pydantic
Interactive API documentation using Swagger UI

Technologies Used ->

Python
FastAPI
Uvicorn
Pydantic

Open the API ->

API: http://127.0.0.1:8000

Swagger documentation: http://127.0.0.1:8000/docs
